<h1 align="center">Binary Search Tree Implementation</h1>

### Description
A templated C++ binary search tree with preorder, inorder, and postorder traversal; structural classification; and a user-record example keyed by account ID.

### Functions
- getRoot()
- insert()
- retrieve()
- isEmpty()
- getHeight()
- remove()
- inOrderDisplay()
- preOrderDisplay()
- postOrderDisplay()
- FullBinaryTree()
- PerfectBinaryTree()
- CompleteBinaryTree()
- BalancedBinaryTree()
- DegenerateTree()
